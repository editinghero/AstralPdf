# Welcome to Astral PDF
A modern, client-side PDF toolkit for compression, merging, conversion, and watermarking — all running entirely in your browser.

## Project Info

**Demo**: https://astralpdf.pages.dev/

## What technologies are used in this project?

This project is built with:

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- PDF-Lib
- pdfjs-dist (PDF.js)
- JSZip
- FileSaver.js
- Heroicons
- Lucide React

Enjoy seamless PDF management without ever leaving your browser!
